FS SARL — SITE VITRINE
========================

Structure:
- index.html : page d'accueil complète
- styles.css : design responsive
- script.js : menu mobile
- assets/ : logo, photos extraites des flyers et flyers recto/verso

Ouverture locale:
1. Décompresser le dossier.
2. Ouvrir index.html dans un navigateur.

Le formulaire de contact utilise l'application email par défaut (mailto) : adaptez-le à votre hébergement si vous souhaitez un traitement serveur des demandes.
