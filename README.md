# FS SARL — Étape 2 du référencement local

Ce pack ajoute la couche SEO locale autour du site actuel :

- pages de services dédiées à Nouakchott ;
- page d’intervention en Mauritanie ;
- maillage interne depuis la page d’accueil ;
- `sitemap.xml` ;
- `robots.txt` ;
- feuille de style `seo-local.css` pour la page d’accueil ;
- feuille de style `service-pages.css` pour les nouvelles pages ;
- guide Google Business Profile ;
- plan de backlinks/citations locales.

## Mise en ligne
1. Remplacer `index.html` du dépôt GitHub par celui de ce pack.
2. Ajouter `seo-local.css` à la racine.
3. Ajouter `service-pages.css` à la racine.
4. Ajouter le dossier `services/`.
5. Ajouter `interventions-mauritanie.html` à la racine.
6. Ajouter `sitemap.xml` et `robots.txt` à la racine.
7. Conserver le dossier `assets/` déjà présent dans le site et ses images existantes.
8. Dans Google Search Console, soumettre `https://www.freedomsalaw.com/sitemap.xml` après publication.

## Important
Les pages parlent de Nouakchott et de la Mauritanie uniquement lorsque cela correspond à l’implantation et au périmètre de service communiqué. Le site évite de créer une page faible pour chaque ville sans contenu réel.
